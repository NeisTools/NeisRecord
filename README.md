# 초등 생기부 도우미

초등학교 학교생활기록부(행동특성, 교과, 창체) 문장 초안을 만드는 PC용 프로그램의 설치 파일을 올려 두는 곳입니다.

- 설치: Releases 에서 최신 `neisrecord-버전-setup.exe` 를 받아 실행합니다.
- 학급 명단과 작성한 글은 이 PC 에만 저장되며 밖으로 보내지 않습니다.
- 인터넷으로 나가는 것은 새 버전 확인과 설치 파일 내려받기뿐입니다.
- 성취기준과 성취수준은 국가교육과정정보센터(NCIC)의 2022 개정 교육과정 공식 자료를 사용합니다.
- 만든 결과는 초안입니다. 실제 관찰한 사실과 기재요령에 맞는지 선생님이 확인한 뒤 사용하세요.
